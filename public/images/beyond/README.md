# Beyond Work photographs

Drop the photographs for the "Beyond Work" section here, then point at them
from `src/data/interests.ts`:

```ts
{ id: 'sailing', label: 'Sailing', icon: 'sailing',
  photo: '/images/beyond/sailing.jpg',
  photoAlt: 'Francisco at the helm, Sai Kung' }
```

**Use the originals, not copies pulled back off social media.** Instagram,
WhatsApp and Facebook all recompress and downscale; those copies look soft
next to the rest of the site. Ask for the file straight off the phone or
camera.

Roughly 4:3 or 3:2, at least 1600px on the long edge, JPEG.
